# IEEE 802.11a Receiver Using Software-Defined Radio (SDR)

## 1. Project Overview

This project focuses on the design and implementation of an IEEE 802.11a wireless LAN receiver using Software-Defined Radio (SDR) techniques.

The project is developed within the Digital Communications (CDIG) course and aims to explore the fundamental principles of wireless signal reception and digital signal processing.

## 2. Objectives

- Understand the IEEE 802.11a physical layer and OFDM transmission.
- Study the main stages of an IEEE 802.11a receiver.
- Implement and evaluate receiver signal-processing blocks.
- Explore synchronization, channel estimation, and signal demodulation, as required by the project specification.
- Validate the receiver's performance through simulations and/or experimental tests.
